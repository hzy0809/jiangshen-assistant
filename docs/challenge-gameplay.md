# 普通挑战

游戏右侧“挑战”入口打开挑战关卡列表。助手的“挑战”页只推进普通关卡：选当前已开启、尚未通关的普通挑战，通关后返回列表重新选择。列表中的精英星级不进入，次数、冷却和资源不购买或重置。

每次启动建立本轮内存状态，读取当前页面，不恢复旧日志。每个正常结算的失败只计一次；胜利不清零，累计失败三次停止。不能确认结果、服务器拒绝或没有可继续的普通目标时提前停止，并显示原因。

| 规则 | 征战推进 | 普通挑战 |
| --- | --- | --- |
| 关卡范围 | 当前未通关主线 | 当前已开启的普通挑战 |
| 失败停止 | 连续三次，胜利清零 | 累计三次，胜利不清零 |
| 已完成关卡 | 不重复挑战 | 不重复挑战，不进入该行后续精英 |
| 开始依据 | 当前游戏页面 | 当前挑战列表或普通挑战页面 |

挑战列表顶部的剩余次数是精英挑战次数。普通挑战不以此数作为启动或停止条件。普通战斗的资源由游戏正常规则和回包决定，助手不承诺所有服务端成本恒为零。

正常操作链为：打开挑战列表、进入普通关卡、选择未击败目标、正常布阵与攻击、等待结算、确认结果与奖励、通关后返回列表。战斗观察和连接生命周期与征战共用；普通关卡的筛选、累计失败计数和范围判断由独立挑战脚本负责。当前指令和回包在本轮核对，日志只作排查。

实际使用与剩余范围记录在 `data/acceptance/20261101-challenge/`；源码实现、构建和实际战斗分别记录。
